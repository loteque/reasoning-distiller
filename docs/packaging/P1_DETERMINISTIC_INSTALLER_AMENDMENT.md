# P1 Deterministic Installer Amendment

Status: **Owner-directed normative amendment**

The V1 installation mechanism is `reasoning-distiller-installer/1`, implemented canonically as the network-independent Python 3 CLI `rd_install.py` executed inside an already-authorized runner.

This amendment clarifies distribution mechanics only. It does not change RGP semantics, project authority, semantic reconciliation, or canonical-memory ownership.

Validation requirements are incorporated into `INSTALL_PACKAGE_CONTRACT.md`, `INSTALLER_RUNNER_CONTRACT.md`, the installation-record schema, and package-contract CI.
